# Java Ticket Machine

## Overview
This project is a Java ticket-machine program developed as part of programming practice using BlueJ.

The program demonstrates basic ticket-machine functionality, including ticket prices, payment balances, and the total money collected.

## Concepts Practiced
- Java classes and objects
- Constructors and instance fields
- Methods
- Variables and arithmetic
- Conditional logic
- Console output

## Tools
- Java
- BlueJ

## What I Learned
This project helped me practice object-oriented programming and understand how methods and variables work together to simulate a simple ticket machine.
